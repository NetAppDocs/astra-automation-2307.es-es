= Puntos finales del certificado Astra API (ACS)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Gestiona los certificados de confianza del administrador que utiliza Astra Control para establecer conexiones salientes.

La API de Certificate App representa certificados en los que confía el administrador y que se utilizan para establecer conexiones salientes.
